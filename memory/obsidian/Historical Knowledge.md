# Historical Knowledge

Historical source knowledge is used to retain failure mechanisms, definitions and evidence limits; it is not a copied operational runbook or current result set. The canonical producer documentation governs the cluster's documented interfaces, while source dates and contradictions stay explicit.

Old wallet/caller identities, rankings, raw logs, databases, results, sessions, credentials, proxy details and generated dashboards are not imported. Historical naming is visible only in the source provenance catalog. The original legacy vaults remain unchanged.

Wallet evidence includes transaction-level accounting, quote orientation/decimal errors, fee-aware win definitions, uncertain tier samples and label-versus-verdict distinctions. The legacy wallet cluster is explicitly cross-referenced into WalletIntel rather than duplicated inside the TokenSniper consumer.
